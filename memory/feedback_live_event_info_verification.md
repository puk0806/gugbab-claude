포켓몬고 10주년 뮤츠 이로치 건(2026-08-19)에서 사용자가 강하게 지적한 조사 방식 오류.

**무슨 일이 있었나:** 리서치 배포 뮤츠의 이로치 가능 여부를 텍스트 웹 문서(위키·가이드·공지)만 뒤져 "사실상 0%"로 단정 → 사용자가 유튜브 인증 영상 하나로 반증. 실제로는 이로치 가능(커뮤니티 실측 1/20). "특별 배경 = 이로치 잠금" 선례를 사실처럼 취급한 확증편향 + "문서에 언급 없음"을 "불가"로 해석한 논리 오류.

**Why:** 라이브 게임 이벤트의 진실은 문서(위키·가이드)가 아니라 유저 인증(유튜브·레딧·디시)에 먼저 올라온다. 위키는 며칠 늦고 공식 공지는 확률·이로치 여부를 잘 안 쓴다.

**How to apply:**
1. 실시간 이벤트/게임 정보는 조사 순서: ① 유저 인증 검색(유튜브 포함 — 검색어에 youtube, 인증, 떴다 등) → ② 공식 공지 교차 확인 → ③ 위키·가이드는 보조
2. 인증을 못 찾으면 "불가/없다"가 아니라 "확인 못 함"으로만 답한다
3. 검색 엔진의 AI 요약문은 원문 fetch로 검증 전에는 인용하지 않는다 (요약이 본문에 없는 내용을 지어낸 사례 있음)
4. 선례·패턴은 추정 근거로만 명시하고 단정형으로 쓰지 않는다
5. **환율·시세 등 수치 데이터는 뉴스 검색 금지, 실시간 소스로 직접 조회** — 예: WebFetch로 `https://open.er-api.com/v6/latest/<통화>` (2026-08-23 엔화 환율 건: 7월 기사 수치를 검색 요약이 최근 날짜에 붙인 걸 그대로 인용해 873원을 907원으로 잘못 답변, 사용자 재지적 받음. 검색 결과 내 수치 모순을 발견하면 반드시 해소 후 답변)
