# 산출물 수정본 전달 방식

PDF·이미지 등 **바이너리 산출물을 고쳐서 다시 줄 때는 같은 파일명으로 덮어쓰지 말고
새 파일명으로 저장하고, 렌더 미리보기(PNG)를 함께 보낸다.**

**Why:**
2026-08-13 근무표 작업에서 `근무표_가로.pdf` 한 이름에 잘못된 버전과 고친 버전을
연달아 덮어썼다. 사용자 PDF 뷰어가 이전 파일을 연 상태여서, 고친 뒤에도 사용자는
계속 잘못된 레이아웃을 보고 "왜 저딴 형태가 나오냐"고 지적했다. 파일은 이미 맞았는데
확인 수단이 없어 왕복이 한 번 더 생겼다.

**How to apply:**
- 수정본 파일명에 내용을 구분하는 이름을 붙인다 (예: `근무표_홀주방_요일상단.pdf`)
- 전달할 때 **PNG 렌더를 같이 보내** 사용자가 열기 전에 바로 확인할 수 있게 한다
- 레이아웃 논쟁이 생기면 말로 반박하지 말고 **좌표를 뽑아 제시**한다
  (예: "요일 전부 y=44 상단 / 홀·주방 전부 x=51 좌측")
- 사진을 재현하는 작업은 [[pdf-photo-reproduction-rotation]] 규칙을 먼저 적용한다
