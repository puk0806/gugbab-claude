# 토큰 95% 소진 시 일시 정지

사용자 지시(2026-08-26): "전부 진행하되 순차적으로, 병렬 가능한 것은 병렬로. **토큰 사용량이 95% 넘어가면 잠시 멈춰라**."

**Why:** 대규모 다단계 작업(스킬 8종 병렬 생성 + 에이전트 + 파이프라인 수정)에서 컨텍스트가 끝까지 소진되면 마무리·보고 없이 끊기는 것을 피하려는 것. 멈춘 지점에서 다음 세션으로 이어갈 수 있게 상태를 남기는 게 목적.

**How to apply:**
- 컨텍스트 예산(`total_tokens left`)을 주기적으로 확인하고, 잔여가 전체의 5% 이하로 내려가면 새 작업을 시작하지 말고 진행 중인 것만 마무리한 뒤 **완료/미완료 목록 + 재개 방법**을 보고하고 멈춘다
- 서브에이전트가 돌고 있으면 결과 수신까지는 기다리되, 수신 후 새 파생 작업은 띄우지 않는다
- 병렬화 판단: 서로 다른 파일을 만드는 스킬 생성·조사는 병렬, README·인덱스 같은 공용 파일 수정은 마지막에 한 번에([[feedback_parallel_readme]])
