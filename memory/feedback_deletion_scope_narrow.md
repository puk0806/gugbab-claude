"학술 스킬·에이전트 제거" 같은 넓은 삭제 요청은 곧바로 넓게 집행하지 않는다. 2026-09-28 사용자는 처음 "학술 관련 제거"라고 했다가 "아리스토텔레스 관련만, 검색·검증 에이전트는 남기고, 잘못된 것까지 삭제하지 말라"로 좁혔고, 이후 "인문 철학·도덕수업 전용"으로 넓혔으며, 경계 묶음(논문 작성 보조)은 질문으로 확정했다.

**Why:** 삭제는 다른 템플릿·에이전트가 의존하는 범용 자산(web-searcher·fact-checker·deep-researcher 등)을 함께 날릴 위험이 크고, 사용자는 의도보다 넓게 지워지는 것을 가장 경계한다.

**How to apply:**
- 삭제 후보를 "확정 / 경계 / 유지"로 나눠 이름 목록으로 먼저 보여주고, 경계 묶음은 AskUserQuestion으로 확정한다.
- 범용 에이전트(검색·검증·리서치 리뷰)는 명시 지시 없이는 삭제 대상에 넣지 않는다.
- 삭제 대상만 쓰던 설치 경로(템플릿 화이트리스트 등)에 **남기는 자산**이 있으면 설치 경로를 다른 템플릿으로 옮겨 고아가 되지 않게 한다(socratic-interviewer → util 사례).
- 미추적 사용자 파일(예: 논문 원고 폴더)은 주제가 같아도 건드리지 않는다.
