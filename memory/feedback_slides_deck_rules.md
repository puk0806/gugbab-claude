2026-10-23 하네스 소개 덱에서 사용자가 크게 화를 냈다.
- 순서 장의 5번 칸만 남색으로 칠해 "왜 5번이 포커싱돼 있냐"는 지적을 받았다.
- 표 칸에 `<b>`·글꼴을 넣어 "원래 있던 내용도 다 사라졌다"는 지적을 받았다.

**Why:** 같은 급의 항목 중 하나만 다르게 칠하면 이유 없는 강조로 보인다. Slides 형식은 표 칸(td/th)에 꾸밈 없는 글자만 받는데, 태그·글꼴을 넣으면 그 칸 내용이 화면에서 빠진다. 화면을 직접 볼 수 없으니 규칙 위반이 그대로 사용자 눈에 드러난다.

**How to apply:**
- 목차·단계·카드 줄은 모두 같은 모양으로 만든다. 강조가 꼭 필요하면 먼저 묻는다.
- 표 칸에는 글자만 넣고 `<b>`·`<span>`·`font-family` 를 넣지 않는다. 칸 스타일은 width·padding·text-align·color 만 쓴다.
- 게시 전에 모든 슬라이드를 스크립트로 검사한다: 형식표의 허용 CSS·위치, 태그 짝, 24px 이상, aside 가 마지막인지, `max-width`·`align-self` 같은 위치 제한 속성.
- 사용자가 "이상하다"고 하면 서버 파일부터 읽어 실제 상태를 확인한다.
