## 1. 덱 계보 (Deck Lineage)

### 1.1 15세기 이탈리아 — 놀이용 트릭테이킹 카드로 출발

| 항목 | 내용 |
|------|------|
| 시기 | 1430년대~1450년대 (Britannica: "created in Italy in the 1430s") |
| 장소 | 북부 이탈리아 궁정 — 밀라노·페라라·베네치아·피렌체·우르비노 |
| 원래 이름 | **trionfi**(트리온피, "승리") → 이후 *tarocchi* → 프랑스어 *tarot* |
| 용도 | **트릭테이킹 카드 게임**. 점술 용도 아님 |
| 성립 방식 | 이미 유럽에 들어와 있던 4수트 56장 카드(맘루크 이집트 경유)에 **영구 트럼프 21장 + 광대(matto)** 를 추가 |

> Met Museum: "the present-day association of tarot with fortune-telling and the occult gained currency only in the 19th century and has nothing to do with the medieval tarot cards."
> 영어 단어 *trump*(으뜸패)는 이탈리아어 *trionfo*에서 왔다.

**현존 최고(最古) 덱 — 비스콘티-스포르차(Visconti-Sforza)**

| 항목 | 내용 |
|------|------|
| 제작 | 약 1440~1480년, 밀라노 |
| 주문자 | 필리포 마리아 비스콘티(밀라노 공작), 프란체스코 스포르차 |
| 화가 | 크레모나의 보니파치오 벰보(Bonifacio Bembo) 공방에 귀속되는 것이 다수설 (프란체스코 자바타리 귀속설도 있음) |
| 소재 | 피어폰트 모건 라이브러리 35장 · 베르가모 아카데미아 카라라 26장 · 베르가모 콜레오니 가문 13장 |

> 주의: 벰보 귀속은 *다수설*이며 학계 논쟁이 완전히 종결된 사항은 아니다. 앱에서 단정 서술하지 말고 "~에게 귀속된다"로 표기한다.

### 1.2 17~18세기 — 마르세유 타로(Tarot de Marseille)

개별 궁정 주문 제작(手描)에서 **목판 인쇄 대량 생산**으로 전환되며 도상이 표준화된 계열.

| 시기 | 사건 |
|------|------|
| 약 1650 | 파리의 장 노블레(Jean Noblet) — 현존하는 가장 이른 마르세유 계열 덱 |
| 1700년대 초 | 장 도달(Jean Dodal) 등 리옹·마르세유 공방이 패턴을 다듬음 |
| 1760 | 마르세유의 니콜라 콘베르(Nicolas Conver) — 이후 표준 원형이 되는 목판 제작 |

특징: 굵은 목판 윤곽선, 스텐실 채색, 프랑스어 카드 명칭, **마이너 아르카나 숫자패는 삽화 없이 수트 기호를 기하학적으로 배열**(pip 카드).

> 주의: 마르세유 계열의 세부 연대·공방 계보는 박물관 1차 소장 기록보다 카드사(史) 연구서·전문 사이트 서술에 의존하는 부분이 있다. 연도를 단정적으로 인용할 때는 Dummett/Depaulis 계열 학술서 재확인을 권한다.

### 1.3 1781년 — 오컬트 전환점 (여기서부터 "고대 지혜" 서사가 시작된다)

| 연도 | 인물 | 한 일 |
|------|------|-------|
| 1781 | 앙투안 쿠르 드 제블랭(Antoine Court de Gébelin) | *Le Monde primitif* 8권에서 "타로 = 고대 이집트 사제들의 『토트의 서』" 주장. **사료 제시 없음.** 당시 이집트 상형문자는 아직 해독조차 되지 않았다(샹폴리옹 해독은 1822년) |
| 1783~ | 에테이야(Etteilla, 본명 Jean-Baptiste Alliette, 1738–1791) | 최초의 직업 카드 점술가. 1789년경 **점술 전용으로 설계된 최초의 덱** *Livre de Thot* 발행 |
| 1854~56 | 엘리파스 레비(Éliphas Lévi) | *Dogme et Rituel de la Haute Magie* — **타로와 카발라(히브리 문자 22자)를 연결한 최초의 알려진 문헌** |
| 1888~ | 황금새벽회(Hermetic Order of the Golden Dawn) | 메이저 22장에 히브리 문자·생명나무 경로·점성 대응을 배정한 체계 완성. 이후 거의 모든 오컬트 덱의 기반 |

**핵심**: 메이저 22장 ↔ 히브리 문자 22자의 "일치"는 고대의 설계가 아니라, **19세기에 숫자가 같다는 이유로 사후 부여된 대응**이다.

### 1.4 1909 — Rider-Waite-Smith (RWS)

| 항목 | 내용 |
|------|------|
| 기획·감수 | 아서 에드워드 웨이트(Arthur Edward Waite, 1857–1942) |
| 작화 | 파멜라 콜먼 스미스(Pamela Colman Smith, 1878–1951) |
| 발행 | 런던 William Rider & Son |
| 시기 | 1909년 스미스가 78장 도안을 위촉받아 약 6개월 만에 완성, **1909년 12월~1910년 초판 발행** |
| 해설서 | 웨이트 *The Key to the Tarot*(1909, 무삽화) → *The Pictorial Key to the Tarot*(1910년 발행, 표기상 1911) |
| 두 사람의 배경 | 둘 다 황금새벽회 회원 |

> **주의(DISPUTED — 발행연도)**: 다수 자료는 1909년 12월 초판 발행으로 기술하나, V&A 소장 기록은 "first published 1910"으로 표기한다. 앱·문서에서는 **"1909–1910"** 또는 "1909년 제작, 1909년 말~1910년 발행"으로 병기하는 것이 안전하다.

**RWS가 바꾼 것**

1. **마이너 아르카나 56장 전체에 서사 삽화**를 넣었다. 이전 주류(마르세유)의 숫자패는 문양 배열뿐이어서 암기가 필요했지만, 삽화 덕분에 초심자가 장면을 읽을 수 있게 되었다 → 오늘날 대중 타로 도상의 사실상 표준.
2. **VIII과 XI를 맞바꿨다.** 전통(마르세유·Britannica 표준 목록)은 VIII 정의(Justice) / XI 힘(Strength)이지만, RWS는 **VIII 힘 / XI 정의**다. 황금새벽회의 점성·카발라 대응(사자자리 Leo가 천칭자리 Libra보다 앞선다)에 맞춘 조정이다.
3. 스미스는 마이너 아르카나에서 사실상 전권을 행사했고, 웨이트는 메이저 도상을 지시했다(V&A 기록).

> **주의(과장 금지)**: RWS를 "최초의 삽화 마이너 아르카나 덱"이라고 쓰면 부정확하다. 선례로 **솔라 부스카(Sola Busca, 1491년 판각, 페라라 추정)** 가 있고, 1907년 부스카-세르벨로니 가문이 78장 흑백 사진을 대영박물관에 기증했으며 스미스가 이를 보았을 가능성이 높다는 것이 통설이다(3 of Swords, 10 of Wands 등 구도 유사). 정확한 표현은 **"대중적으로 널리 보급된 최초의 완전 삽화 덱"**.

### 1.5 20세기 이후 — 현대 덱

| 계열 | 예 | 성격 |
|------|-----|------|
| RWS 파생 | 무수한 "RWS 클론"·리디자인 덱 | 78장 구조와 장면 구성을 계승. 오늘날 시장 다수 |
| 오컬트 독자 체계 | 토트(Thoth) 덱 — 알레이스터 크로울리 기획, 프리다 해리스 작화 | 카드명·대응이 RWS와 다름. RWS 키워드를 그대로 적용하면 오독 |
| 마르세유 부흥 | 콘베르 계열 복원판 | pip 카드 전통 유지, 해석 방식도 다름 |
| 현대 창작 덱 | 아티스트·출판사 창작 | 전량 저작권 보호 대상 (§4) |

> 앱 설계 시: **덱 계열이 다르면 키워드 체계도 다르다.** 하나의 해석 DB로 모든 덱을 커버하지 말고, "이 앱은 RWS 전통 기준"임을 명시한다.

### 1.6 오컬트 기원설 — 역사적 근거 없음 (정정표)

| 흔한 주장 | 실제 |
|-----------|------|
| 고대 이집트 『토트의 서』에서 유래 | 1781년 쿠르 드 제블랭의 **사료 없는 추정**. 상형문자 미해독 시기의 주장 |
| "tarot"은 이집트어 "왕의 길"에서 유래 | 어원학적 근거 없음. 이탈리아어 *tarocchi* 계열 |
| 집시(로마니)가 인도·이집트에서 전파 | 사료로 뒷받침되지 않음. 카드는 이탈리아 궁정 문서에 먼저 등장 |
| 카발라 생명나무를 도상에 담아 설계 | 카발라 연결은 **1854년 레비가 최초**로 제시. 15세기 덱과 무관 |
| 고대부터 점술에 쓰였다 | Dummett의 분석 결론: **18세기 이전에 점술·오컬트 용법은 확인되지 않는다** |

> 앱 카피에 "고대 이집트의 지혜" 같은 문구를 넣지 않는다. 문화사적으로 틀린 서술이며, 이용자 신뢰를 깎는다.

## 2. 덱 구조와 대표 상징 (RWS 기준)

### 2.1 전체 구조 — 78장

```
78장
├── 메이저 아르카나 (Major Arcana / Trumps) 22장
│     0 광대(The Fool, 번호 없음 또는 0) + I~XXI
└── 마이너 아르카나 (Minor Arcana) 56장
      └── 4수트 × 14장
            ├── 숫자패(pip) 10장 : Ace(1) ~ 10
            └── 코트카드 4장 : Page · Knight · Queen · King
```

> "아르카나(arcana, 비밀)"라는 명칭 자체도 15세기 것이 아니라 **오컬트 전통에서 붙인 용어**다.

### 2.2 메이저 아르카나 22장 — 표준 순서

Britannica 표준 목록(마르세유 전통) 기준. **괄호는 RWS 명칭/번호 차이**.

| No. | 전통 명칭 | RWS 명칭 |
|:---:|-----------|----------|
| 0 / 무번호 | 광대 (Fool) | The Fool |
| I | 마술사·요술쟁이 (Juggler/Magician) | The Magician |
| II | 여교황 (Papess) | The High Priestess |
| III | 여황제 | The Empress |
| IV | 황제 | The Emperor |
| V | 교황 (Pope) | The Hierophant |
| VI | 연인 | The Lovers |
| VII | 전차 | The Chariot |
| VIII | **정의 (Justice)** | **Strength (힘)** ← RWS에서 교체 |
| IX | 은자 | The Hermit |
| X | 운명의 수레바퀴 | Wheel of Fortune |
| XI | **힘 (Strength/Fortitude)** | **Justice (정의)** ← RWS에서 교체 |
| XII | 매달린 사람 | The Hanged Man |
| XIII | 죽음 | Death |
| XIV | 절제 | Temperance |
| XV | 악마 | The Devil |
| XVI | 벼락 맞은 탑 | The Tower |
| XVII | 별 | The Star |
| XVIII | 달 | The Moon |
| XIX | 태양 | The Sun |
| XX | 심판 | Judgement |
| XXI | 세계 | The World |

> 데이터 모델링 시 **`number`(로마숫자)와 `name`을 분리 저장**하고, 덱 계열 필드(`marseille` / `rws` / `thoth`)를 둔다. VIII·XI 교체를 하드코딩하면 마르세유 덱 지원 시 깨진다.

### 2.3 마이너 아르카나 4수트

| RWS 수트 | 전통 이탈리아 | 오컬트 전통의 원소 대응 | Britannica가 기술하는 주제 영역 |
|----------|---------------|------------------------|-------------------------------|
| Wands (완드/지팡이) | Batons/Bastoni | 불 (Fire) | 사업·일 |
| Cups (컵) | Coppe | 물 (Water) | 사랑·감정 |
| Swords (검) | Spade | 공기 (Air) | 갈등 |
| Pentacles (펜타클) | Coins/Denari | 흙 (Earth) | 돈·물질 |

> **주의**: 수트-원소 대응은 **황금새벽회 시기(19세기 말)에 정착한 관례**이며 15세기 놀이 카드에는 없던 개념이다. "원래부터 4원소를 상징했다"고 쓰지 않는다.

코트카드 위계: Page(시종) < Knight(기사) < Queen(여왕) < King(왕).
(마르세유 계열은 Valet/Cavalier/Reine/Roi — 명칭만 다르고 4단 구조는 동일)

### 2.4 RWS 대표 상징 — 구조 수준

카드별 전면 해설은 **웨이트 본인의 *The Pictorial Key to the Tarot*(1910/1911, 퍼블릭 도메인)** 를 1차 자료로 인용한다. 아래는 앱이 참조할 *반복 모티프* 수준의 정리다.

| 모티프 | 등장 | 도상적 기능 |
|--------|------|-------------|
| 4원소 도구(지팡이·잔·검·펜타클) | 마술사의 탁자 | 4수트 전체를 한 장에 압축 — 마이너와 메이저를 잇는 구조적 장치 |
| 두 기둥 | 여사제 (B/J 기둥) | 대립쌍 사이의 문턱·경계 |
| 무한대 기호(∞) | 마술사, 힘 | 순환·지속 |
| 천체 3연작 | 별 XVII → 달 XVIII → 태양 XIX | 밤에서 낮으로 향하는 연속 시퀀스로 배치됨 |
| 흰 장미 / 백합 | 광대, 마술사, 죽음 등 | 순수 / 욕망의 대비 짝 |
| 스핑크스 | 전차, 운명의 수레바퀴 | 수수께끼·운의 축 |
| 숫자 진행 | 각 수트 Ace→10 | Ace(잠재)에서 10(완결·포화)으로 가는 서사 축 |

**"바보의 여정(Fool's Journey)"**: 광대(0)가 I~XXI를 차례로 거치며 성장한다는 서사 틀. **20세기 후반 대중 타로 해설서에서 정착한 현대적 교육 장치**이며, 웨이트나 15세기 원전이 제시한 구조가 아니다.

> 주의: 개별 카드의 "정통 의미"는 존재하지 않는다. 같은 카드도 저자·시대·덱마다 다르게 서술된다. 앱은 **단일 정답 톤이 아니라 "이 전통에서는 이렇게 읽어 왔다"** 로 제시한다.

## 3. 심리학적 해석 전통 — 융 원형론과 타로

### 3.1 융이 실제로 말한 것 (전부)

융의 타로 관련 직접 발언은 **다음 정도가 확인되는 전부**에 가깝다. 이 이상을 융에게 귀속시키지 않는다.

| 출처 | 내용 |
|------|------|
| *The Archetypes of the Collective Unconscious*, CW 9i, §81 | "타로 카드의 그림 세트도 **변용의 원형(archetypes of transformation)에서 멀리 파생된 것처럼 보인다**. 이 견해는 베르누이 교수의 매우 계발적인 강연으로 확인되었다" — 연금술 이미지 연속체를 논하는 문단의 곁가지 언급 |
| 1930-09-16 에크슈타인 부인에게 보낸 편지 | "타로를 안다. 내가 아는 한 스페인 집시가 쓰던 카드로, 역사적으로 알려진 가장 오래된 카드다" |
| 1933-03-01 세미나(적극적 상상 강의). *Visions: Notes of the Seminar Given in 1930–1934*, Princeton UP, 1997, p.923 | 타로를 "상징적 상황의 그림들"로, "무의식의 흐름의 일반 구성물과 뒤섞이는, 분화된 성격의 **원형적 관념들**"로 언급 |

**중요 — 융의 역사 인식 자체가 틀렸다**: 1930년 편지의 "스페인 집시 기원, 가장 오래된 카드"는 **역사적으로 오류**다(§1.1, §1.6). 융을 "타로 역사의 권위"로 인용하면 안 된다.

### 3.2 과장 금지 — 자주 유통되는 잘못된 서술

| ❌ 잘못된 서술 | ✅ 정확한 서술 |
|---------------|--------------|
| "융이 타로를 연구해 원형론을 세웠다" | 원형·집단무의식 이론은 신화·종교·연금술·꿈 자료에서 나왔다. 타로는 곁가지 언급 수준이다 |
| "융은 타로를 치료에 사용했다" | 그런 임상 기록은 확인되지 않는다 |
| "메이저 22장 = 융의 원형 22개" | 융은 원형을 22개로 열거한 적이 없다. 숫자 대응은 후대 타로 저자들의 도식이다 |
| "융이 타로가 무의식과 통한다고 증명했다" | 융은 증명한 바 없다. "원형에서 멀리 파생된 듯 보인다"는 인상 서술이다 |

> 정확한 프레이밍: **"융 자신의 타로 언급은 단편적이며, 오늘날의 '융 심리학적 타로'는 융 이후 저자들(폰 프란츠 이후 세대·현대 타로 저술가)이 원형·투사·개성화 개념을 타로에 적용해 발전시킨 해석 전통이다."**

### 3.3 "예언 도구 vs 자기성찰·투사 도구" 논쟁

| 입장 | 논지 | 근거 상태 |
|------|------|-----------|
| **예언(divinatory)** | 카드 배열이 외부 사건·미래 정보를 담는다. 융의 동시성(synchronicity) 개념을 원용하는 경우가 많다 | **경험적 지지 없음.** 예측 정확도를 입증한 통제 연구가 존재하지 않는다. 동시성 개념 자체도 반증 가능한 과학 가설이 아니다 |
| **자기성찰·투사(projective)** | 카드는 모호한 시각 자극이며, 내담자가 자기 내용을 투사해 서사를 구성한다. 로르샤흐·모래놀이와 유사한 표현적 도구 | 상담·심리치료 문헌에 소규모 연구·사례 보고가 존재한다(예: 타로를 상담의 투사 기법으로 다룬 학위논문·저널 논문). **다만 표본이 작고 진단 도구로서의 타당도는 확립되지 않았다** |

**투사 기법 자체의 한계도 함께 알려야 한다**: 로르샤흐를 포함한 투사 검사 전반은 심리측정학적 타당도·신뢰도 논쟁이 오래 지속된 영역이다. "심리학이 타로를 인정했다"고 말하면 과장이다. 정확히는 **"표현적·성찰적 보조 도구로 쓰려는 시도와 제한적 연구가 있다"**.

### 3.4 리딩이 "맞는 것처럼" 느껴지는 이유 — 인지 메커니즘

앱이 반드시 알고 있어야 할 설명 틀. 사용자를 비난하는 톤이 아니라 **투명성 확보용**으로 쓴다.

| 현상 | 내용 |
|------|------|
| **바넘 효과 / 포러 효과** | 누구에게나 들어맞는 일반적 서술을 "나에게 딱 맞는다"고 느끼는 경향. 포러(Bertram R. Forer)의 1948년 실험에서, 전원에게 동일한 성격 기술문을 주었는데 각자 자기 것이 정확하다고 평가했다 |
| **콜드 리딩** | 확률 높은 일반 진술로 시작해 반응을 관찰하며 좁혀가는 기법. 대면 리딩의 "적중감"을 상당 부분 설명한다 |
| **확증 편향 · 주관적 검증** | 맞은 부분은 기억하고 빗나간 부분은 잊는다 |

> 이 메커니즘 자체가 **성찰 도구로서의 가치를 부정하지는 않는다.** 모호한 자극에 자기 이야기를 투사하는 과정이 자기 이해에 도움이 될 수 있다는 것과, 카드가 미래를 안다는 것은 완전히 별개의 주장이다. 앱은 이 둘을 반드시 분리해서 말한다.

## 4. 저작권·라이선스 — 앱에 카드 이미지를 넣기 전에

> 아래는 **공개 자료에 기반한 정리이며 법률 자문이 아니다.** 상업 배포 전에는 관할 지역 변호사 검토를 받는다.

### 4.1 RWS 원본 이미지 (1909/1910)

| 관할 | 상태 | 근거 |
|------|------|------|
| **미국** | **퍼블릭 도메인** | Cornell 저작권 기간표: 1931년 이전에 발행된 저작물은 미국 내 저작권 만료. **미국 밖에서 최초 발행된 외국 저작물도 1931년 이전 발행이면 미국 내 PD** |

> **주의(DISPUTED)**: 과거 영국법상 "도안을 위탁한 자가 권리자"라는 해석 때문에 웨이트 기준(2013)과 스미스 기준(2022) 사이에서 다툼이 있었다. 스미스로부터 웨이트에게 저작권이 양도되었음을 입증하는 문서는 확인되지 않는다. **2026년 현재는 어느 해석을 취하든 원본은 보호기간을 지났다**는 점만 확정적으로 기술한다.

### 4.2 그런데도 함부로 못 쓰는 이유 — 2차 저작물과 상표

| 리스크 | 내용 | 대응 |
|--------|------|------|
| **U.S. Games Systems 1971년 리컬러 판** | 원본과 다른 채색·리터치가 들어간 현대 판본. 출판사가 별도 저작권을 주장한다 | **1971년 이후 상업 판본 스캔을 쓰지 않는다.** 1909/1910 초판 계열 스캔만 사용 |
| **"Rider-Waite" 상표** | 미국에서 등록 상표로 관리되며, 플랫폼(마켓플레이스·앱스토어) 태그·제목에 쓰면 자동 테이크다운이 걸릴 수 있다. Dastar 판례를 근거로 만료 저작물에 상표를 덧씌우는 것을 다툴 여지가 있다는 견해가 있으나, **분쟁 비용은 별개 문제다** | 앱 이름·스토어 키워드에 "Rider-Waite" 상표를 쓰지 않는다. **"Waite–Smith 전통 기반", "RWS 계열 도상 참고"** 등으로 표기 |
| **현대 창작 덱 / 마르세유 복원판** | 20세기 이후 제작 덱은 원칙적으로 보호 대상. 마르세유 계열도 *복원·재채색판*은 신규 권리가 주장될 수 있다 | 반드시 개별 라이선스 취득. 무단 스캔 금지 |

> 주의(미검증): 특정 현대 덱(토트 덱 등)의 개별 만료 시점은 저작자별 사망 연도·관할별 규정에 따라 달라진다. 본 스킬은 개별 연산 결과를 제공하지 않는다 — 사용 전 개별 확인.

### 4.3 실무 의사결정 순서

```
1) 자체 일러스트를 새로 제작한다        ← 가장 안전. 상징 구조(§2)만 참조

   └ 출처 아카이브의 이용 조건(스캔 제공자 표시 요구 등)도 확인
3) 현대 덱 라이선스 구매                ← 계약서에 앱 내 디지털 사용·재배포 범위 명시
4) 1971년 이후 상업 판본 스캔 사용      ← 금지
```

- 스토어 메타데이터(제목·부제·키워드)에 타사 상표 미포함

## 5. 앱 적용 시 톤 가이드 — 필수 준수

### 5.1 금지 표현

❌ "당신은 이번 달 안에 이직하게 됩니다"
❌ "이 카드가 나왔으니 그 사람과는 안 됩니다"
❌ "탑 카드는 불행이 닥친다는 뜻입니다"
❌ "고대 이집트에서 전해진 비의(祕儀)"
❌ "융이 증명한 무의식의 언어"
❌ "이 카드는 건강에 문제가 있다는 신호입니다" (의료 암시 — 절대 금지)

### 5.2 권장 표현 (hedging 톤)

✅ "이 카드는 웨이트-스미스 전통에서 …를 상징해 온 카드입니다"
✅ "탑은 전통적으로 갑작스러운 변화·기존 구조의 붕괴를 나타내는 이미지로 읽혀 왔습니다. 무엇이 지금 흔들리고 있다고 느끼시나요?"
✅ "타로는 미래를 알려주는 도구라기보다, 지금의 생각을 정리해 보는 계기로 쓰실 때 도움이 됩니다"
✅ "이 해석은 여러 전통 중 하나이며, 다르게 읽는 관점도 있습니다"

### 5.3 응답 템플릿

```
{카드명} — {수트/메이저 구분}

웨이트-스미스 전통에서 이 카드는 {전통적 상징}을 나타내는
이미지로 읽혀 왔습니다. {도상 요소}가 그 예입니다.

지금 상황에 비춰 본다면:
{성찰 질문 1~2개 — 단정 아닌 질문 형태}

※ 타로 해석은 문화적 상징 전통이며 미래를 예측하는 검증된
   방법이 아닙니다. 중요한 결정은 충분한 정보와 상의를 거쳐
   내리시기 바랍니다.
```

### 5.4 응답 시 필수 포함

1. **예언 단정 금지** — 미래형 단정문("~할 것입니다")을 출력하지 않는다
2. **자기성찰 프레이밍** — 해석을 서술이 아니라 **질문**으로 되돌린다("어떤 부분이 지금과 겹치나요?")
3. **전통 귀속 명시** — "웨이트-스미스 전통에서는", "마르세유 전통에서는"
4. **부정적 카드에 안심 문구 동반** — 죽음·탑·악마 등은 불안 유발 가능. "전통적으로 종결·전환의 이미지로 읽히며, 실제 사건을 예고하는 것이 아닙니다" 병기
5. **소재 범위** — 재미로 보는 앱이므로 의료 진단, 법률 판단, 투자·도박 권유, 임신·사망 예측, 타인의 감정·행동 단정은 어떤 카드가 나와도 다루지 않고 상징 풀이에 머문다
