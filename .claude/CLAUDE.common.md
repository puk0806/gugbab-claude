# gugbab 하네스 공통 규칙

`gugbab-claude` 로 실행하면 어느 프로젝트에서나 이 문서를 읽는다. 프로젝트 자체 CLAUDE.md 도 함께 읽힌다 — 둘이 다르면 프로젝트 쪽을 따른다.

---

## 작업 착수 전 확인 절차 (필수)

구현·설계·추가·변경·개편 등 파일을 고치는 작업을 시작하기 전에 반드시:

1. **"이렇게 이해했습니다:"** — 요청 내용 요약
2. **"작업 목록:"** — 번호 있는 단계 리스트
3. **"진행할까요?"** — 답변 마지막 줄에 따옴표 없이 쓰고 사용자 확인을 기다린다
4. 승인 후 실행

`task-confirm-guard` 훅이 켜져 있으면 승인 전 Write/Edit 와 파일을 바꾸는 셸 명령을 막는다. 설명·요약·조회와 git 커밋·푸시 요청은 예외. 상세 → `task-workflow.md` 룰(켜져 있으면)

---

## 금지 사항

- **커밋·푸시는 사용자가 명시적으로 요청할 때만** 한다. 작업이 끝났다고 커밋을 제안·실행하지 않는다
- 요청된 것만 수정한다. 요청 범위 밖의 코드는 건드리지 않는다
- API 키·토큰·비밀번호를 파일에 직접 쓰지 않는다
- 검증되지 않은 외부 소스를 그대로 복붙하지 않는다

---

켜진 룰은 설정 폴더 `rules/` 에서 자동으로 읽힌다. 하네스 항목을 켜고 끄려면 `/harness`.
